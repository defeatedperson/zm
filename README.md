# 幻梦桌面 (LivePaper)

Windows 动态壁纸工具：把视频或图片设为桌面壁纸，多屏独立管理，好看更省资源。

官网：<https://zm.xcdream.com>


## 功能特性

- **画廊式管理**：视频/图片素材集中管理，点击封面一键应用到全部屏幕
- **多屏独立**：每块显示器可设置不同壁纸，支持按屏幕清除、一键恢复静态壁纸
- **无缝循环**：双解码通道 + 交叉淡入，循环播放无卡顿、不闪黑
- **视频优化**：一键将高规格素材转码为适合屏幕的分辨率/帧率（H.264 硬件编码），原件自动备份
- **智能暂停**：检测到全屏应用时自动暂停对应屏幕的壁纸；锁屏、息屏自动暂停，回到桌面自动恢复
- **手动暂停**：托盘或右键菜单随时冻结/恢复画面
- **开机自启**：登录后自动启动，并恢复每块屏幕上次的壁纸
- **本地运行**：无联网、无遥测，所有数据仅保存在本机

## 系统要求

- Windows 10（1809 及以上）/ Windows 11
- WebView2 运行时（Windows 10/11 通常已内置）

## 下载安装

前往 [官网](https://zm.xcdream.com) 或本仓库 [发布](../../releases) 页面下载安装包，双击安装即可。

## 使用说明

1. 点击「添加素材」导入视频（mp4/webm/m4v）或图片（jpg/png/webp/bmp/gif）
2. 点击卡片封面，将壁纸应用到全部屏幕；右键卡片可指定单块屏幕
3. 顶部状态条显示每块屏幕的使用状态，点 `✕` 恢复该屏静态壁纸
4. 高分辨率素材建议在卡片菜单中使用「优化」转码，以降低解码占用

## 从源码构建

环境要求：Node.js 18+、Rust（MSVC 工具链）、Windows 10/11。

```bash
npm install

# 本地开发
npm run tauri dev

# 打包 NSIS 安装程序（输出于 src-tauri/target/release/bundle/nsis/）
npm run tauri build -- --bundles nsis
```

## 技术栈

- [Tauri 2](https://v2.tauri.app/) + Vue 3 + Vite
- Rust + Win32（WorkerW 桌面层挂载）+ Media Foundation（硬解/硬编）
